# 🎓 Meus Estudos: Learning & Development

Este repositório serve como um hub central para todos os meus estudos de programação. Aqui documento minha evolução, anotações e projetos práticos realizados em diversas plataformas de ensino.

O objetivo é manter um histórico organizado da minha jornada acadêmica e técnica, consolidando conceitos de arquitetura, boas práticas e novas tecnologias.

---

## 📂 Organização

Atualmente, o repositório está dividido por plataformas de ensino e tecnologias para facilitar a localização de cada estudo:

* **Alura**: Estudos de Java, Spring Boot e boas práticas de desenvolvimento.

---

## 🚀 Como navegar

As pastas seguem a hierarquia: `Plataforma > Tecnologia > Assunto`. 
Basta navegar pelos diretórios para encontrar o código-fonte de cada módulo estudado.
